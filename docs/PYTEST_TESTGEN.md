# Python Pytest Test Case Generation

## Overview

ESBMC now supports automatic generation of pytest test cases for Python programs. This feature uses symbolic execution and SMT solving to automatically discover test inputs that achieve high code coverage.

## Usage

### Basic Command

```bash
esbmc example.py --generate-pytest-testcase
```

This will generate a `test_case.py` file containing pytest test cases.

### Input Format

Your Python code should use `__VERIFIER_nondet_*()` functions to mark symbolic inputs:

```python
# example.py
def check_positive(n: int) -> int:
    """Check if a number is positive and return its double"""
    assert n > 0, "Number must be positive"
    return n * 2

# Test generation mode: use nondet inputs
a = __VERIFIER_nondet_int()
check_positive(a)
```

### Output Format

ESBMC will generate a pytest file like this:

```python
# test_case.py
# Auto-generated by ESBMC v7.x
# Original file: example.py

from example import *
import pytest

@pytest.mark.parametrize("a", [
    (5),    # Test case 1 (counterexample)
])
def test_check_positive(a):
    """Auto-generated test cases for check_positive()"""
    check_positive(a)
```

### Running the Tests

```bash
# Run the generated tests
pytest test_case.py

# Run with coverage
pytest test_case.py --cov=example --cov-report=html
```

## Supported Types

- `__VERIFIER_nondet_int()` → Python int
- `__VERIFIER_nondet_bool()` → Python True/False
- `__VERIFIER_nondet_float()` → Python float

## Example: Multiple Parameters

```python
# example.py
def add_positive(a: int, b: int) -> int:
    """Add two positive numbers"""
    assert a > 0 and b > 0, "Both numbers must be positive"
    return a + b

# Test generation mode
x = __VERIFIER_nondet_int()
y = __VERIFIER_nondet_int()
add_positive(x, y)
```

Generated output:

```python
# test_case.py
from example import *
import pytest

@pytest.mark.parametrize("x,y", [
    (5, 3),     # Test case 1
    (10, 1),    # Test case 2
])
def test_add_positive(x, y):
    """Auto-generated test cases for add_positive()"""
    add_positive(x, y)
```

## How It Works

1. **Symbolic Execution**: ESBMC translates your Python code to an internal representation and performs symbolic execution
2. **SMT Solving**: The SMT solver finds concrete values for the symbolic inputs (`__VERIFIER_nondet_*`)
3. **Test Generation**: These concrete values are extracted and formatted as pytest test cases
4. **Coverage**: The generated tests can be run with pytest's coverage tools to measure code coverage

## Comparison with C Test Generation

This feature is similar to the existing `--generate-testcase` flag for C programs, but outputs pytest-compatible Python test files instead of XML.

| Feature | C (`--generate-testcase`) | Python (`--generate-pytest-testcase`) |
|---------|---------------------------|---------------------------------------|
| Input Format | `int a = __VERIFIER_nondet_int();` | `a = __VERIFIER_nondet_int()` |
| Output Format | XML (Test-Comp format) | Python (pytest format) |
| Test Execution | Test-Comp tools | pytest |
| Coverage Measurement | Test-Comp | pytest-cov |

## Benefits

✅ **Automated**: No need to manually write test cases
✅ **Coverage-Driven**: ESBMC finds inputs that cover different branches
✅ **Integration**: Works seamlessly with pytest ecosystem
✅ **Validation**: Generated tests verify assertions in your code

## Limitations

- Currently generates one test case per counterexample found
- Best suited for testing individual functions with symbolic inputs
- Does not currently support complex Python types (lists, dicts, objects)
