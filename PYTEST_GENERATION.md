# Python Pytest Test Case Generation

ESBMC now supports automatic generation of pytest test files from counterexamples for Python programs.

## Overview

This feature extends the existing `--generate-testcase` functionality (originally for C programs in Test-Comp XML format) to Python by generating executable pytest test files.

## Implementation Approach

### Architecture (照抄C的实现)

The implementation follows the same architecture as C test generation:

1. **Extract input values**: Traverse `SSA_steps` to find variable assignments
2. **Query SMT solver**: Get concrete values from `smt_conv.get()`
3. **Format output**: Generate pytest code instead of XML

```cpp
// Core logic (90% same as C version)
for (auto const &SSA_step : target.SSA_steps) {
  if (SSA_step.is_assignment()) {
    auto value = smt_conv.get(SSA_step.lhs);  // Same as C

    // Type conversion (same logic)
    if (is_constant_int2t(value))
      pytest_file << to_constant_int2t(value).value.to_int64();
    else if (is_constant_floatbv2t(value))
      pytest_file << float_value;
    // ...
  }
}
```

### Key Differences from C

| Aspect | C (Test-Comp XML) | Python (pytest) |
|--------|------------------|-----------------|
| Output format | `<input>0</input>` | `x = 0` |
| Variable naming | Anonymous sequence | Named variables |
| Execution | External tool reads XML | Direct `pytest` execution |
| Exception handling | Implicit | Explicit `pytest.raises()` |

## Usage

### Basic Example

```bash
# Run ESBMC on a Python file
$ esbmc example.py --generate-testcase

# Output: test_counterexample.py
```

### Generated Test File Format

For this input:

```python
# example.py
def div1(cond: int, x: int) -> int:
    if not cond:
        return 42 // x
    else:
        return x // 10

cond = 0
x = 0
result = div1(cond, x)
```

ESBMC generates:

```python
# test_counterexample.py
"""
Auto-generated pytest test file from ESBMC counterexample.

This test reproduces a bug found by ESBMC symbolic execution.
Generated by ESBMC 7.7

Violation: division by zero
Property: x != 0
"""
import pytest
from example import div1


def test_div1_counterexample():
    """
    Test case generated from ESBMC counterexample.

    This test should trigger the bug found by ESBMC.
    Run with: pytest test_counterexample.py
    """
    # Input values from counterexample
    cond = 0
    x = 0

    # This call should reproduce the bug
    with pytest.raises(ZeroDivisionError):
        result = div1(cond, x)


def test_div1_manual():
    """
    Manual test - customize this to verify the fix.
    """
    # TODO: Add test cases for correct behavior after fixing the bug
    pass
```

### Running the Generated Test

```bash
$ pytest test_counterexample.py -v

test_counterexample.py::test_div1_counterexample PASSED ✓
test_counterexample.py::test_div1_manual SKIPPED

========================= 1 passed, 1 skipped in 0.01s =========================
```

## Multi-Property Mode

When using `--multi-property`, ESBMC generates separate test files for each counterexample:

```bash
$ esbmc example.py --multi-property --generate-testcase

# Output:
# test_counterexample_1.py
# test_counterexample_2.py
# test_counterexample_3.py
```

## Supported Exception Types

The generator intelligently detects the violation type and uses appropriate pytest exceptions:

| Violation Type | pytest Exception |
|----------------|-----------------|
| Division by zero | `ZeroDivisionError` |
| Array bounds | `IndexError` |
| Assertion failure | `AssertionError` |
| Other | `Exception` |

## Code Structure

### Modified Files

1. **src/goto-symex/witnesses.h** (Line 241-247)
   - Added `generate_testcase_python()` declaration

2. **src/goto-symex/witnesses.cpp** (Line 1179-1432)
   - Implemented `generate_testcase_python()` function
   - Extracts variables from SSA steps (same as C)
   - Formats output as pytest code

3. **src/esbmc/bmc.cpp** (Line 156-174, 495-517)
   - Detects Python files by `.py` extension
   - Routes to Python or C generator accordingly

### Core Logic Flow

```
goto_trace (counterexample)
    ↓
extract variables from SSA_steps
    ↓
query SMT solver for concrete values
    ↓
format as pytest test code
    ↓
test_counterexample.py
```

## Future Enhancements

Potential improvements:

1. **Multiple test methods**: Generate one test method per input combination
2. **Test suite generation**: Aggregate multiple counterexamples into one file
3. **Complex types**: Support for lists, tuples, classes
4. **Parametrized tests**: Use `@pytest.mark.parametrize`
